1. Welcome

Thank you for reading the DiceLab benchmark report. This is a cross-language experiment where the same dice-rolling simulation is implemented in five languages:

  • C++
  • Go
  • Java
  • Python
  • Rust

Each language was tasked to run several sized workloads (number of 6-sided dice rolls per simulation), and data was stored to measure how fast my home computer could run each implementation. The initial implementation does not include containerization, but I plan to explore Docker in the future for others to run and compare against these results. Other languages may also be implemented in the future.

The report is organised around three questions:

  • How do the five implementations compare at the same workload size?
  • How does each implementation scale as rolls grow from 100 to 1 million?
  • How consistent (repeatable) is each language's timing across many trials?

Everything here is interactive. Charts are powered by Plotly.js, so you can hover for details, zoom into regions, and toggle traces on and off via the legend. Several sections include dropdowns to switch between workloads or languages. I’ve also included my own commentary throughout — look for the blue “Author’s take” boxes. The a code that generates this report is available to explore on my GitHub.
