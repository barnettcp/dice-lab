The chart below plots total batch elapsed time against batch run index. A downward trend at the start is the expected signature of warm-up effects: the OS’s branch predictor, file-system cache, and — in Java’s case — the JVM’s JIT compiler all improve over the first few runs. A rising trend or high late-run variance would suggest sustained system load or thermal throttling.
